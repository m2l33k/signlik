🚀 Sign Registration Integration Examples

💡 Tip: This page shows different ways to integrate the Sign Registration feature into your application.

Standalone Usage

Simply open sign-registration.html in a browser. No integration needed!

Iframe Embed

Embed the sign registration page in your application using an iframe:

<iframe src="sign-registration.html" style="width: 100%; height: 800px; border: none;" title="Sign Registration" ></iframe>

Module Integration

Use the JavaScript functions directly in your application:

// Example: Add sign programmatically async function addSignFromYourApp() { const file = document.getElementById('yourFileInput').files[0]; const name = document.getElementById('signName').value; const formData = new FormData(); formData.append('file', file); formData.append('name', name); formData.append('description', 'Description here'); formData.append('category', 'greetings'); formData.append('difficultyLevel', 'beginner'); const token = localStorage.getItem('jwt_token'); const response = await fetch('http://localhost:8081/api/signs/add', { method: 'POST', headers: { 'Authorization': `Bearer ${token}` }, body: formData }); const result = await response.json(); console.log('Sign added:', result); }

Direct API Usage

Use the REST API directly from your frontend:

// Get all signs fetch('http://localhost:8081/api/signs') .then(r => r.json()) .then(signs => console.log(signs)); // Search signs fetch('http://localhost:8081/api/signs/search?query=hello') .then(r => r.json()) .then(signs => console.log(signs)); // Get sign by ID fetch('http://localhost:8081/api/signs/1') .then(r => r.json()) .then(sign => console.log(sign));
